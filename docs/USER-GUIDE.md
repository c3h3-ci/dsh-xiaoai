# dsh-xiaoai 使用指南

> 让小米音箱成为 DSH 的语音入口 —— 不只是聊天，而是**能真实操作你的家**

## 一、它能做什么

### 1. 智能家居控制（已验证）
对着音箱说：
- "把储藏室灯打开" → 设备真实打开，语音确认
- "台灯现在是什么状态？" → 读出当前状态
- "家里有几盏灯？" → 统计并回答

**支持 264+ 个可控设备**（灯、开关、插座、浴霸…），由 Home Assistant 提供。

### 2. 信息查询与问答（已验证）
- "今天上海天气怎么样？" → 联网搜索并播报（含台风预警这类附加信息）
- "帮我查一下上证指数" → 调用行情接口
- 任意知识问答 → 由 DSH 的 LLM 回答

### 3. 上下文记忆（已验证）
```
你：请记住，我最喜欢的颜色是蓝色
音箱：好的

你：我最喜欢的颜色是什么？
音箱：你最喜欢的颜色是蓝色。
```
同一个音箱的对话**共享上下文**，可以追问、指代。

### 4. 可扩展（DSH 的全部能力）
音箱背后是 DSH agent，它还能：
- 发邮件、读文档
- 浏览器自动化
- 运行命令、读写文件
- 调度子任务

> 具体能用哪些，取决于你的 DSH 配置了哪些工具。

## 二、三种唤醒方式

### 方式 1：直接问（推荐日常使用）
配置 `callAIKeywords`（如 `["请","帮我"]`）后：
```
"帮我查下天气"   ← 命中"帮我" → 直接交给 DSH
```

### 方式 2：进入 AI 模式（连续对话）
配置 `wakeUpKeywords`（如 `["进入AI模式"]`）：
```
你：进入AI模式
音箱：AI模式已开启          ← 之后所有话都交给 DSH，无需重复喊关键词

你：今天几号
音箱：...

你：退出
音箱：已退出AI模式
```
**30 秒无对话会自动退出**（`exitKeepAliveAfter` 可调）。

### 方式 3：全部转发（默认，零配置）
不配任何关键词时，**所有听到的话都转发给 DSH**。
适合：你想让音箱接管一切对话。

> ⚠️ 注意：这会把「小爱同学，放首歌」这类指令也转走。
> 建议配置 `ignorePatterns` 或改用方式 1/2。

## 三、首次接入（4 步）

```
第 1 步：选择接入方式
  ○ 自动导入（推荐）—— 扫描本机 MiGPT / Home Assistant 的已有凭据
  ○ 账号登录 —— 手机号 / 邮箱 / 小米 ID 都可以
  ○ 手动配置 —— 专家模式

第 2 步：提供凭据
  自动导入：选一个扫描到的凭据即可（零输入）
  账号登录：填账号密码；若触发小米风控会显示授权链接

第 3 步：选择音箱
  从列表里点选（不用知道 DID），系统自动匹配型号指令集

第 4 步：测试连通
  点「测试音箱」，听到声音就成功了
```

### 关于小米风控
异地登录时小米会要求网页验证，界面会给出**授权链接**。
完成授权后**约需等待 1 小时**账号信息才更新，请稍后重试。

## 四、配置项速查

### 必填
| 项 | 说明 |
|---|---|
| 小米 ID | 数字 ID（登录后自动获取，不用手填）|
| 密码 | 小米账号密码（敏感，界面会打码）|
| 音箱 DID | 从「发现音箱」列表里选，不用手填 |

### 音箱侧（体验相关）
| 项 | 默认 | 说明 |
|---|---|---|
| 唤醒词 | 空 | 说这些话进入 AI 模式 |
| 直接问 | 空 | 说这些话直接交给 DSH |
| 退出词 | 空 | 说这些话退出 AI 模式 |
| 超时退出 | 30 秒 | AI 模式下静默多久自动退出 |
| 进入/退出/思考提示语 | 有默认 | 空数组 = 不播报 |

### 会话绑定
| 项 | 说明 |
|---|---|
| 工作目录 | 语音会话落在哪个工作区（默认 `~/.dsh/im`）|
| Agent 预设 | 用哪个预设（默认跟随 Host）|
| 模型 | provider + model（默认跟随 Host）|
| 复用会话 | 开启则保持上下文（推荐）|

### 行为
| 项 | 默认 | 说明 |
|---|---|---|
| 轮询间隔 | 4000ms | 多久查一次小米云（最小 2000）|
| 回复超时 | 240s | 等 DSH 回复的最长时间 |
| 最大回复字数 | 400 | 播报会被截断到这么长（音箱念太长很难受）|

## 五、常见问题

### 音箱没反应？
1. 看面板「最近听到」有没有你的话 —— 没有则是**没抓取到**（检查小米连接）
2. 有听到但没回复 —— 看「最近回复」和运行日志
3. 检查是否被"待机"状态拦住了（面板会显示当前模式）

### 回复是"我收到了，但没想出怎么回答"？
这是**兜底文案**，说明 DSH 处理失败。看运行日志里的具体错误。

### 提示"账号需要重新登录"？
小米 token 过期（约 15-24 小时）。插件会自动用密码重新登录；
若反复失败，请到面板重新保存一次凭据。

### 台灯点了没反应？
**可能是设备离线**。agent 会主动复核状态并如实报告
（"指令已发出但状态未改变"）。到 HA 里确认设备是否在线。
